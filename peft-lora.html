PEFT and LoRA

How to fine-tune a model and change only a small part of it.

1. Full fine-tuning

Full fine-tuning changes all weights in the model. This method works. But it has three problems.

Problem 1: Training uses much memory

Inference keeps only the weights in memory. Training keeps more data for each weight:

  • The weight.
  • The gradient. This value tells training which direction to move the weight.
  • The optimizer state. The Adam optimizer keeps two more values for each weight.

Thus, training needs approximately 3 to 4 times the memory of inference.

Memory for weights and training data. (Activations also use memory. This diagram does not show them.)

Problem 2: Each fine-tuned version is a full copy

If you fine-tune for five tasks, you get five full models. You must store and serve each one.

Problem 3: The model can forget

All weights move toward your small dataset. The model can lose skills that it had before. This problem is catastrophic forgetting.

2. PEFT: Parameter-Efficient Fine-Tuning

PEFT uses a different method:

  1. Freeze all weights in the base model.
  2. Add a small number of new weights (the adapter).
  3. Train only the adapter.

The base model does not change.

3. LoRA: Low-Rank Adaptation

LoRA is the most used PEFT method.

The main idea

Fine-tuning adds a change to each weight matrix. Call this change ΔW ("delta W").

Research shows that ΔW is usually "low-rank." This means that ΔW has a simple structure. You can make it from two thin matrices. You multiply them together.

Analogy. A large spreadsheet can look complex. But if each row is a multiple of a small set of patterns, you only need to store the patterns and the multipliers. LoRA stores the patterns (A) and the multipliers (B).

BA has the same shape as ΔW. But B and A together have 32 times fewer weights.

How the model uses the adapter

The input goes on two paths. The model adds the two results.

Output h = W·x + (α/r)·B·A·x  =  (W + (α/r)·BA)·x

  • W does not change. Training changes only A and B.
  • At the start of training, B is all zeros. Thus BA is zero, and the model behaves exactly like the base model.
  • For deployment, you can merge BA into W. Then inference has no extra cost.

4. Configure the adapter

Four settings control the adapter.

r (rank)

r is the thin dimension of A and B. It sets the capacity of the adapter.

Each step doubles r. Each step doubles the adapter weights (for one 512 × 512 matrix).

  • Higher r: the adapter can learn more.
  • Higher r with a small dataset: the adapter can memorize the data (overfit).
  • Usual values: 4 to 16.

lora_alpha

lora_alpha scales the effect of the adapter. The real multiplier is lora_alpha ÷ r.

  • Set lora_alpha to r (multiplier = 1) or to 2 × r (multiplier = 2).
  • In the example below: 16 ÷ 8 = 2. The adapter output is doubled.
If you change r, also change lora_alpha. Keep the same ratio. Then the adapter strength stays about the same.

target_modules

target_modules tells LoRA which layers get an adapter. Each attention layer has four projections: q (query), k (key), v (value), and o (output). For FLAN-T5, the usual choice is ["q", "v"].

lora_dropout

Dropout sets some adapter inputs to zero at random during training. This prevents the adapter from memorizing the data.

  • Usual range: 0.0 to 0.1.
  • Use a higher value with a small dataset.
  • Dropout is active only during training. It is off during inference.

5. The code

# Import the configuration class and the task types.
from peft import LoraConfig, TaskType

lora_config = LoraConfig(
    task_type=TaskType.SEQ_2_SEQ_LM,  # Model has an encoder and a decoder (FLAN-T5).
    r=8,                              # Thin dimension of A and B.
    lora_alpha=16,                    # Scale = 16 / 8 = 2.
    target_modules=["q", "v"],        # Add adapters to query and value projections.
    lora_dropout=0.05,                # Drop 5% of adapter inputs during training.
    bias="none"                       # Keep all bias terms frozen.
)

Note on the numbers. The 512 × 512 example is a simplification. In FLAN-T5-small, the q and v projections are 512 × 384 (6 heads × 64). The idea is the same. With the config above, FLAN-T5-small gets approximately 340,000 trainable weights. That is less than 0.5% of the 77 million weights in the model.

Summary

  1. Full fine-tuning changes all weights. It uses much memory, makes full copies, and can cause forgetting.
  2. PEFT freezes the base model. It trains only a small adapter.
  3. LoRA is a PEFT method. It learns two thin matrices, B and A. Their product BA is the weight change.
  4. The output is (W + (α/r)·BA)·x. W does not change.
  5. r sets capacity. lora_alpha ÷ r sets strength. target_modules sets location. lora_dropout reduces overfitting.
