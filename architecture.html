Summarizing customer-support call transcripts with FLAN-T5-small, served over HTTP with FastAPI.

Serving ML runtime Model hub Config / tooling Scripts

Runtime architecture (main.py)

Client

POST /summarize
  • text (required)
  • max_length = 150
  • min_length = 15
→

uvicorn + FastAPI + pydantic

uvicornfastapi
  • uvicorn: ASGI server
  • FastAPI: routing, threadpool for sync handler
  • pydantic: validates request (extra=forbid) and response
  • Empty text → 422, errors → 500
→

transformers + torch

transformerstorch
  • Tokenizer (max 512 tokens)
  • FLAN-T5-small seq2seq model
  • Beam search, 4 beams, no_grad
  • CUDA fp16, otherwise CPU fp32
→

Response

{ "summary": "..." }

huggingface-hub

huggingface-hub
  • Downloads google/flan-t5-small weights once, then caches locally (used by transformers at startup)
  • InferenceClient for the hosted API (explore.py)
  • scan_cache_dir (check_cache.py)

python-dotenv

python-dotenv
  • Loads .env (e.g. HF_TOKEN); .env is gitignored

uv + uv_build

  • Dependency pinning (uv.lock), Python ≥ 3.12
  • Package skeleton in src/ is unused boilerplate

Request lifecycle

1. Validatepydantic schema, reject blank text
→
2. Promptprefix "Summarize the following dialogue:"
→
3. Tokenizetruncate to 512, move to device
→
4. Generatebeam search with min/max length
→
5. Decodetoken IDs → text, skip special tokens
Startup (once, at import) load_dotenv → pick device → load tokenizer + model (from HF cache or download) → model.to(device).eval()

How the scripts evolve toward main.py

FilePackagesWhat it does
explore.pyhuggingface-hub, dotenvBaseline: calls hosted facebook/bart-large-cnn via the HF Inference API (needs HF_TOKEN).
explore_local.pytransformersFirst local run of FLAN-T5 on one hardcoded ticket, CPU only.
explore_safe.pytransformers, torchAdds device selection, fp16 on GPU, input validation, try/except returning None.
explore_batch.pytransformers, torchsummarize_batch(): padding, attention mask, batches of 8, batch_decode.
check_cache.pyhuggingface-hubReports size of cached models on disk.
main.pyfastapi, uvicorn, pydantic, transformers, torch, dotenvWraps the single-text logic in a validated /summarize HTTP endpoint.
